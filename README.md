## Utilisation de la branche correction

Pour lancer ce projet, assurez-vous de basculer sur la branche `correction`, qui contient les dernières corrections et mises à jour. Suivez les étapes ci-dessous :

```bash
1. Clonez le dépôt et accédez au répertoire du projet :

   git clone https://github.com/ikhela-04KK/Nexsphere-capital-app
   cd Nexsphere-capital-app

2. Basculez sur la branche correction :

   git checkout correction

3. Installez les dépendances du projet :

   npm install

4. Démarrez le serveur de développement :

   npm run dev

5. Ouvrez votre navigateur et accédez à http://localhost:3000 pour voir le projet en action.
